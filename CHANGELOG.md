# Changelog

All notable changes to the project are recorded here. Data corrections must also identify affected record IDs and releases in the release-specific correction log.

## [Unreleased]

- Implementation of the v1 delivery tracks and release gates.

## [0.2.0] — 2026-07-19

### Added

- production-oriented roadmap from pilot through stable v1.0;
- formal v1 release criteria and definition of done;
- twelve delivery-track charters;
- architecture, security, support, maintainer, operations, and release-process documentation;
- outcomes-evidence catalogue data contract and template;
- stronger validation and continuous-integration expectations;
- release-readiness and correction templates;
- GitHub Projects operating model, v1 epic backlog, and gate/epic issue templates.

### Changed

- v1.0 is now defined as a stable, reproducible, governed, secure, and maintainable product rather than only a global census milestone;
- project plan now distinguishes feature delivery, hardening, release-candidate assurance, and post-release maintenance.

## [0.1.0] — 2026-07-19

- Initial repository scaffold, seed registers, schemas, methods notes, and lightweight validation.
