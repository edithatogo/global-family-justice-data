# Quality layer

The target release pipeline writes machine-readable and human-readable assurance outputs here, including:

- validation errors and warnings;
- row counts and referential-integrity results;
- source freshness and retrieval status;
- lineage completeness;
- second-review backlog;
- anomaly and reconciliation reports;
- audit sample and adjudication summaries;
- prior-release differences;
- coverage by region, language, matter type, source type, and outcome domain.

Generated quality reports are release artifacts. They should be versioned and archived with the data rather than treated as disposable logs.
