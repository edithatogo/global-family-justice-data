# GFJD cross-repository medallion compatibility

The immutable `v1` through `v4` directories are byte-identical portable
contracts and canaries from `edithatogo/global-medicines-atlas`. Versions 1–3
are also byte-identical to the copies in `edithatogo/archive-govt-nz`. They are
vendored under the upstream Apache-2.0 licence and remain unchanged.

`gfjd-layer-mapping-v1.json` is the GFJD-authored compatibility profile. It
keeps GFJD's native layer meanings distinct while projecting them into the
shared vocabulary. It is a technical mapping, not federation registration,
rights clearance, evidence acceptance, publication or release authority.
