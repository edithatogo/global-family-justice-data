# Gold layer

Gold contains approved analytical indicators suitable for the explicitly stated comparison. It is generated from retained inputs and is never hand-edited.

Every gold row requires:

- exact source and transformation lineage;
- approved indicator and matter mapping;
- source-quality grade;
- comparability Tier 1 or Tier 2;
- independent second review;
- approved review status;
- release identifier and schema version.

Tier 3 and Tier 4 records remain in silver and cannot enter direct-comparison tables. Release-specific quality and limitations reports must accompany gold data.
