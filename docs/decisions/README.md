# Decision records

Material governance, scope, ontology, comparability, security, licensing, and architecture decisions should be stored here as numbered records.

A decision record includes:

- status: proposed, accepted, superseded, rejected;
- decision owner and date;
- problem and evidence;
- options considered;
- compatibility and jurisdiction impact;
- risks, dissent, and safeguards;
- decision and rationale;
- implementation and migration plan;
- review or expiry date.

Decisions are not rewritten after approval. A later record may supersede an earlier one.
