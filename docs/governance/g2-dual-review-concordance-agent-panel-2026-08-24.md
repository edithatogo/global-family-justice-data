## Options

1. **Bounded supporting acceptance — recommended.** Accept the exact result and
   conservative methods dispositions as supporting owner-adjudicated evidence,
   while leaving every criterion and work-item status unchanged.
2. **Criterion progression.** Create new acceptance-bearing records and accept
   C04/C05 for this limited cohort. This makes faster programme progress but
   risks overstating a calibrated two-row exercise and was not the majority
   panel recommendation.
3. **Defer all disposition.** Wait for broader unseen-edition evidence. This is
   maximally conservative but fails to recognise a valid bounded result and
   leaves already-resolved handling questions artificially open.

## Recommendation, trade-offs and contingencies

Adopt option 1. Preserve the exact result as supporting evidence, accept the
no-pooling/no-ranking disposition, and restrict the dashboard to same-series
cross-format reconciliation and DataJud to private aggregate acquisition
support. The trade-off is no immediate criterion transition. If later unseen
evidence passes, bind it separately rather than enlarging this decision. If a
new discrepancy, source edition, field contract or semantic conflict appears,
reopen the affected methods disposition and keep the observation quarantined.

No panel member claims authority to accept a G2 criterion, clear rights,
release a row from quarantine, publish, release or pass G2.
