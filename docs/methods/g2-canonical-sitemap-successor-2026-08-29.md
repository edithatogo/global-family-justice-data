# G2 canonical sitemap successor — 2026-08-29

The streaming predecessor stopped correctly when the first frozen non-canonical
New Zealand child-sitemap URL returned an unpermitted redirect. This distinct
prospective lineage freezes the three observed canonical trailing-slash
endpoints and removes that locator defect without repairing or reusing the
failed execution.

Execution is strictly sequential. Endpoint 1 is the only initially permitted
request. Endpoint 2 becomes eligible only after endpoint 1 passes its HTTP,
binding, byte, XML, exposure and completeness interlocks; endpoint 3 is gated
the same way. The first failure terminates the lineage, with zero retries and no
redirect following.

The stage remains manifest-only. It permits neither candidate-document access
nor extraction, G2 acceptance, publication or release.
