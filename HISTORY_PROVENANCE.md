# Git history provenance

This distribution contains a real, cloneable Git history reconstructed on **27 July 2026** from the project checkpoints available in the working environment.

The history preserves the evolution of the delivered artefacts through annotated checkpoint tags:

- `checkpoint-v0.1` — initial source-census scaffold;
- `checkpoint-v0.2.0` — v1 roadmap, governance and release contracts;
- `checkpoint-v0.3.0` — hardened conductor, pipeline and release controls;
- `checkpoint-v0.4.0-alpha.1` — multi-format ingestion, evidence, comparability and resilience tooling;
- `checkpoint-v0.4.0-alpha.3` — CI, supply-chain and distribution-assurance controls;
- `checkpoint-v0.6.0-alpha.1` — Codex handoff, clone discovery and remote bootstrap;
- `handoff-v0.6.0-alpha.2` — verified self-bootstrapping distribution.

This is **checkpoint reconstruction**, not a claim that the files originally existed in a prior upstream Git repository with these exact commit hashes or timestamps. The builder identity on the reconstructed commits is intentionally a project-build identity. Codex should preserve this history and append new commits using the operator’s verified local Git identity.
