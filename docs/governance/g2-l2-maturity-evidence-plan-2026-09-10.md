# G2 L2 maturity evidence plan

**Status:** repository-owned preparation; not a maturity assessment or G2 acceptance

G2 requires an evidence-assured maturity floor of L2 across all ten dimensions.
The current floor is L1. Existing accepted policy and architecture records are
valid repository controls but do not, by themselves, prove L2 operation.

## Qualification rule

Each dimension must have a digest-bound evidence record whose status is `accepted`
and whose scope demonstrates repeatable execution, not merely a design or planned
control. The maturity assessor must record the exact scope, run receipts, negative
checks, limitations and owner decision. A single dimension without qualifying
evidence keeps the floor at L1.

## Work packages

| Dimensions | Repository-owned evidence that can be prepared now | Evidence still required before L2 |
|---|---|---|
| M01, M02 | Owner decision bindings, replay contracts and role-separated advisory reports | Current owner adjudication of the assembled maturity matrix |
| M03 | Reconciled census/coverage manifests and deterministic gap calculations | Reviewed current coverage/enquiry results for the declared cohort |
| M04, M05, M06 | Real B0 custody checks, deterministic replay, field lineage and layer-specific tests | Multi-route empirical replay and owner acceptance of factual outputs |
| M07 | Product contract, accessibility checks and metadata validation | Deterministic private pilot download/profile rehearsal; no public-beta claim |
| M08 | Aggregate-only safety and quarantine tests | Current rights/privacy/security/disclosure assessment for each edition |
| M09 | Correction, restore and monitoring rehearsals | Operated custody/restore evidence and current service ownership |
| M10 | Localisation/federation contract validation | Source-language agent review, authoritative triangulation and a dated owner commitment for the bounded pilot |

## Execution order

1. Freeze a maturity matrix and evidence manifest at a signed commit.
2. Run role-separated advisory checks over the frozen matrix; record dissent and
   limitations without calling the result independent assurance.
3. Execute repository-owned replay, lineage, safety and accessibility checks using
   exact B0 bindings; retain outputs outside Git where they contain source bytes.
4. Obtain or record the remaining factual hosted/operational records. Missing or
   ambiguous records remain `in_review`, `metadata_only` or quarantined.
5. Recompute the assured floor. Do not raise any dimension to L2 until its own
   evidence is accepted; do not average dimensions or borrow evidence across them.

The plan does not authorize network access, source acquisition, rights clearance,
publication, release, Gold promotion or G2 passage.
