# Threat model baseline

Protected assets include children and families, source confidentiality, credentials, release integrity, provenance, contributor identities and institutional independence. Principal threats are accidental personal-data inclusion, malicious source content, server-side request forgery, credential leakage, dependency compromise, unauthorised programme-state changes, false evidence acceptance, release substitution and denial of public access.

Baseline controls include an aggregate-only public boundary, private-network URL rejection, bounded downloads, content hashing, rights routing, protected branches, review separation, secret scanning, deterministic release manifests, audit logging, least privilege, backup and restore rehearsals, and independent release verification. Threats and mitigations must be reviewed before G2, G4, G5 and after material incidents.
