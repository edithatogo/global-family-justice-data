# Rights and redistribution control

Each acquisition records rights status separately from redistribution permission. When redistribution is not explicitly allowed, the public repository stores only metadata, checksum, source locator and controlled-access route. Restricted or uncertain material is never copied into public release artefacts.

Rights review covers publisher terms, database rights, copyright, confidentiality, archival permission, automated-access conditions and required attribution. Takedown requests are logged, assessed and answered under the incident and corrections process without silently rewriting historical releases.
