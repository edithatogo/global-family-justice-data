# Prospective dynamic-source continuation

## Owner direction and scope

The owner said “Proceed with your recommendations” after the September 6
cleanup/recovery plan recommended a new prospective BRA/dashboard capture as
the fallback to unavailable original artifacts. This records implementation of
that direction, not a gate decision, personal signature or rights clearance.
The original ODS is recovered; old API/dashboard packets and failures remain
unchanged. New captures have new identities and cannot establish old responses.

The exact initial stage is frozen in
`data/methods/g2/G2-DYNAMIC-SUCCESSOR-20260907-01/plan.json` together with
`scripts/capture_g2_dynamic_successor.py` under a signed repository commit before
execution. It makes at most three requests, sequentially: official DataJud public
key documentation, one current class-1389 TJSP aggregate request, and the already
recorded dashboard models/exploration endpoint. There are no retries, redirects,
searches, alternate endpoints, source substitution or target dashboard POSTs.
TLS connects to a validated public peer with hostname verification.

The public key exists only in process memory and the request header. Neither
credentials nor raw responses are published. Each attempt is checkpointed before
requesting; source retention occurs only after boundary checks, using exclusive
files with mode 0600 inside a fresh 0700 ignored source vault. Existing vaults
prevent reruns, including after an interrupted or failed attempt. Any failed
transport, schema, byte, identity or prohibited-data check terminates the stage.
Review retention by 2027-08-24. This is local custody, not provider-separated
preservation. Recovery metadata remains public; no source byte publication occurs.

## Role-separated advice incorporated

The source-scope advisory agent reviewed the historical packets without network
access. Its recommendations are applied as follows:

- Preserve the BRA class filter, size-zero query and source-defined semantics;
  do not label the result annual filings, national coverage or historical data.
- Reject nonempty case hits, failed shards, approximate/truncated counts,
  unexpected aggregation content and class buckets outside 1389.
- Require explicit dashboard model and visual identity, not an ID substring.
  Reject unreviewed root fields, nested row/record material and contact signals
  before retention. A models GET is structural metadata only.
- Never reconstruct the missing old query from narrative filters or use an old
  numeric result as a selection or validation oracle.

The final pre-execution advisory review found no remaining blocker for this
three-request stage. Structural screening is not comprehensive privacy assurance;
retained metadata remains private and quarantined pending review. Legitimate but
unrecognized provider metadata can trigger a terminal schema stop, not an
automatic relaxation or retry. Twenty-one offline fixture tests passed before
the freeze; their responses are fictional and are not empirical evidence.

Options: retrieving a fresh source-defined query from matching visual and
conceptual schema preserves route coverage but needs a subsequent exact query
and semantic freeze. Guessing expressions would be cheaper but unsupported and
is prohibited. If source configuration is insufficient, retain the stop evidence
and explain the missing contract; do not silently narrow the cohort.

## Conditional next stage and limits

Only explicitly source-derived schema/query evidence can support the next query
freeze. There is no automatic endpoint discovery or dashboard query in this
stage. A passing structural stage is not a qualifying concordance result.
Once that exact source contract exists, the approved continuation uses two fresh
artifact-isolated extraction agents, an offline exact comparator and separate
source-accuracy advice. Old outputs and expected values are excluded from role
bundles. Critical agreement remains 100%, populated-field agreement at least 99%;
failure is terminal, without repair, reuse, fuzzy matching or waiver. Source
period labels, retrieval dates and reporting universes remain distinct; equal
values alone establish no equivalence. A passing result returns for one grouped
owner adjudication. No G2 passage, maturity promotion, rights clearance or release
is authorized here.

Resource estimate: at most 12MB transferred across three calls with 30-second
socket timeouts; at most 11MB of validated source bodies retained. No spend or
outbound contact is involved. This bounded stage may stop before all calls.
