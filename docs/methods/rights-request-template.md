# Rights and redistribution request template

Use this draft for a publisher contact. An agent may prepare it; the request
must be sent by the repository owner or an authorised account.

Subject: GFJD permission request — [source title]

Hello [publisher/contact],

I am the analyst-owner of the Global Family Justice Data repository
([repository URL]). We would like permission to [describe the exact use:
link/cite, store a metadata receipt, reproduce selected tables, or redistribute
derived observations] for **[source title, edition/date, URL]**.

The project is public, non-commercial research infrastructure. We will retain
source attribution, edition/date, retrieval timestamp, and a SHA-256 receipt;
we will not redistribute the source files unless you expressly permit that
use. Please confirm the permitted use, attribution wording, any restrictions,
and the appropriate licence or written permission record.

Regards,
[repository owner]

## Evidence to retain

- sent message and recipient identity;
- response or explicit no-response closure date;
- exact source edition and URL;
- permission scope and attribution wording;
- reviewer decision recorded in the source register and review ledger.
