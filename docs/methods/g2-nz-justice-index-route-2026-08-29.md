# G2 New Zealand justice-statistics index route

This prospective route observes the exact New Zealand Ministry of Justice justice-statistics index before its expected September update. It freezes four family-justice spreadsheet locators and the visible page-update text without opening any returned file.

The page currently exposes malformed machine-readable date text (`2026-45-17`). The monitor records but rejects that attribute as publication-date evidence. The visible `17th March 2026` text is a baseline change detector only. Any date or locator change stops for exact-edition and official publication-date review.

This route cannot itself establish candidate eligibility, reproducibility, maturity L2, rights clearance, G2 passage, publication, or release.
